# FormAPI examples and agent skill

Free starters for HTML, Next.js and Astro, plus a portable coding-agent skill. Product: https://getformapi.com/en. Spanish docs: https://getformapi.com/es/docs.

- `html/`: plain HTML, CSS and JavaScript.
- `nextjs/`: Next.js App Router, TypeScript and shadcn/ui (Base UI) Button/Input/Label/Textarea primitives.
- `astro/`: static Astro page.
- `skills/formapi-integration/`: SKILL.md and Codex UI metadata. Copy the folder into `.agents/skills/` (Codex), `.cursor/skills/` (Cursor) or `.claude/skills/` (Claude Code) in your project.

Read each README, set your public endpoint, and test before publishing. No private credentials are included. This repository contains integration examples, not the private FormAPI application. MIT license.
